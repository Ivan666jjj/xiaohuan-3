# 小焕三号 · 残字候选检索

用「补全 + 双通道检索」让残缺字形的检索能力追平完整字形。

## 结论

| 情况 | Top-1 | Top-5 | Top-20 |
|---|---|---|---|
| 完整字形（上限） | 20.4% | 39.6% | 59.2% |
| 残缺字形（遮挡 30%）直接检索 | 14.8% | 34.8% | 56.8% |
| **补全 + 双通道融合** | **20.4%** | **41.6%** | **59.2%** |

残字检索在补全后追平完整字形，Top-5 反超 2 个点。

## 方法

1. **补全**：Pix2Pix 风格生成器（U-Net + PatchGAN），输入残缺字，输出完整字。
2. **检索**：4 层 CNN + 度量学习，输出 Top-20 候选。
3. **双通道融合**：原图特征与补全图特征按 0.7 : 0.3 加权。

## 三个关键发现

- **像素质量与检索脱钩**：v1 补全后 PSNR 从 30.77 降到 28.05（补得不像），检索却提升 4.8 点。该看结构相似，不是像素相似。
- **感知损失要用领域内特征**：用本任务的 CNN 特征做感知损失（而非 VGG），PSNR 从 28.05 升至 33.48。
- **遮挡增强损害检索**：训练 loss 从 5.15 降到 1.25，检索却全面下降——检索要清晰字形特征。

## 七组实验

详见 [docs/report.html](docs/report.html)。

| 实验 | 方案 | R1 | 结论 |
|---|---|---|---|
| 1 | 多样遮挡训练（20 轮） | 15.2% | 训练不足 |
| 2 | AdaBN 域适应 | 3.2% | 无效 |
| 3 | 补全 v1（20 轮） | 19.6% | 有效，PSNR 28.05 |
| 4 | 补全 v2（50 轮 + 字形特征损失） | 20.0% | 更好，PSNR 33.48 |
| 5 | 双通道融合（w=0.7） | **20.4%** | 最优 |
| 6 | 多样遮挡训练（50 轮） | 17.6% | 失败：过拟合 |
| 7 | 迭代补全（2 次） | 19.6% | 无增益 |

## 快速开始

```bash
cd src
python3 server.py
# 浏览器打开 http://127.0.0.1:8765
```

需要 `numpy`、`torch`、`pillow`。模型权重需自行训练（见 `src/exp4_gan_v2.py`）。
