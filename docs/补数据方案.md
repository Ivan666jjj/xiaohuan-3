## 三、三条补数据的路

### A. 同源扩充（北大秦简剩余部分）—— 推荐

- **已有材料**：全书 25 卷、338 页 PDF，释文印在每简左侧
- **做法**：切字 → 按 x 坐标取左侧释文对齐 → 人工抽检
- **预计产出**：每类从 2 个提到 5–10 个
- **风险**：低。同一批简，字形风格一致，不会“负迁移”

### B. 异源扩充（里耶秦简、岳麓秦简、睡虎地秦简）

- **需要**：新的图版 + 释文（出版物或数据库）
- **风险**：中。不同批简的字形风格有差异，可能学成“混血”反而更差
- **建议**：先用 A 做出效果，再考虑 B

### C. 伪标签（用当前模型给未标注图打标）

- **快**，但会放大现有错误
- **建议**：只做“辅助筛图”，不单独当训练数据

## 十、同源扩充的实地抽检（2026-11-05 晚）

### 发现：材料比想象的多，但质量比想象的差

`beida/pairs.json` 里已有 **13,997 个自动检测的字框**，覆盖全书 344 页、1,446 类。

| 项目 | 数值 |
|---|---|
| 已用于训练/测试 | 2,564 |
| 未使用 | 11,432 |
| 未使用中落在训练类别内的 | 7,872（68.9%） |

**看起来可以直接扩容 4 倍。但抽检 30 个后，结论相反。**

### 抽检结果（30 个随机样本）

| 情况 | 数量 | 说明 |
|---|---|---|
| 标签与字形相符 | 约 10 | 雨、下、年、大、山、錢、田、貸、田、大 |
| **空白或污损框** | **4** | 无字、木纹、墨团，标签无意义 |
| 字形模糊、无法核验 | 约 16 | 笔画粘连或残缺，人眼也难定 |

**至少 13% 是无效框**，其余有相当比例标签不可靠。这与之前“扩充到 5,664 字反而掉点”完全吻合。

### 为什么会这样

自动流程是：PDF 渲染 → 检测墨迹列 → 按列切字框 → 用左侧释文按顺序对齐。

问题出在最后一步：**按顺序对齐，一旦中间少框或多框，后面全错位**。加上空白框、污损框也被计入，标签与字形就错开了。

### 正确的扩充做法（修正版）

```
1. 墨迹过滤：统计每个框的墨迹密度，去掉空白框（预计可去掉 10–15%）
2. 尺寸过滤：去掉过扁（高 < 20px）或过窄的框
3. 重新对齐：不按顺序硬配，改用「字形识别 + 释文校验」双向确认
4. 人工抽检 200 个：错误率 < 5% 才入库
5. 只用合格部分训练
```

### 一个残酷但要说的事实

**自动对齐这条路，之前已经失败过一次。** 这次抽检证明，问题不在模型，在数据管道。

要真正扩充，得有一步人工核验。**没有捷径。**

### 现实的工作量

| 步骤 | 时间 | 产出 |
|---|---|---|
| 墨迹/尺寸过滤 | 1 小时 | 去掉约 1,500 个无效框 |
| 重新对齐（算法） | 半天 | 待核验数据 |
| 人工抽检 200 个 | 3 小时 | 错误率 |
| 合格部分入库 | 1 小时 | 正式训练集 |

**总计 1–2 天**，但前提是有人愿意花 3 小时核验。
